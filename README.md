# Vivek Saini — React Developer Portfolio

A personal portfolio website showcasing my skills, projects, and experience as a Frontend Developer. Built with React.js and Vite, featuring a responsive interface and a modern design.

## 🌐 Live Demo

**[View My Portfolio](https://portfolio-react-gamma-ecru.vercel.app/)**

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Home section with profile introduction
- About section highlighting my background and skills
- Featured projects with live demo and GitHub links
- Contact section for professional inquiries
- Dark mode support
- Resume available to view or download
- Interactive navigation and UI elements

## 🛠️ Tech Stack

- **Frontend:** React.js, JavaScript
- **Styling:** CSS3
- **Build Tool:** Vite
- **Icons:** Lucide React
- **Version Control:** Git and GitHub
- **Deployment:** Vercel

## 🚀 Run Locally

Follow these steps to run the project on your computer.

### 1. Clone the repository

```bash
git clone https://github.com/saini06vivek/portfolio-react.git
```

### 2. Navigate to the project directory

```bash
cd portfolio-react
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the portfolio.

### 5. Build for production

```bash
npm run build
```

The production-ready files will be generated in the `dist` directory.
